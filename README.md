# Mail
This is a Cross platform mail application. This was intended for my use on Linux to replace Geary because of design issues I had with it.

# Dioxus version
This is currently very slow and doesn't feel native.

### Features:
- [] Send Mail
- [] Receive Mail
- [X] View Mail
- [X] BCC Mail
- [x] CC Mail
- [] Delete Mail
- [] View Attachments
- [] Download Attachments
- [X] View HTML Mail
- [X] View Plain Text Mail
- [] View Mail Headers
- [] View Mail Source
- [] View Mail Raw
- [] View Mail Flags
- [] View Mail Size
- [X] View Mail Date
- [X] View Mail Subject
- [X] View Mail From
- [] Add ICS Calender
- [] Offset Timezone for ICS Calender
